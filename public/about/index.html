— The case for a reading room

Your AI keeps writing. Where does it all go?

Modern coding agents leave a trail. ARCHITECTURE.md here, PROPOSAL.md there, plans and post-mortems scattered across folders nobody opens twice. Your repository accumulates documentation faster than anyone can read it.

What's missing is a place to read. A quiet, opinionated viewer that holds the entire archive in one sidebar — searchable, editable and as easy to scan as a printed book. Readme Viewer is that place. Local-first, paper-quality typography, no upload.

What's inside

Ten product choices
№ 01 — BROWSING

Pick a folder, get a library.

Point Readme Viewer at any directory on your machine. It scans recursively, hides the noise (node_modules, .git, dist, build), and surfaces every .md file in a tidy, collapsible tree. Searches respect your folder structure, never the irrelevant parts.

№ 02 — SEARCH

File or full-text, one keystroke.

Toggle between filename and content search. Matching snippets are shown with surrounding context — you remember what each document was about, not just what it was called.

№ 03 — EDITING

Double-click to edit.

Any block becomes a textarea on double-click. Tables edit cell by cell. Commit writes straight back to disk — no separate editor, no copy-paste tax.

№ 04 — DIAGRAMS

Mermaid, rendered.

```mermaid blocks become real diagrams in both light and dark mode. Re-themed automatically when you toggle.

№ 05 — TYPOGRAPHY

Built for reading.

Long-form vertical rhythm, careful heading scale, accent colours that don't shout. Dark mode that's actually comfortable to read in.

№ 06 — PRIVATE

Nothing leaves your device.

Files are read through the browser's File System Access API. There is no server, no upload, no analytics. Close the tab and the access is gone — like never opening the file.

№ 07 — PWA

Installs like a native app.

Add to your dock or taskbar. Register .md files to open in the viewer by default. Works offline thanks to a small service-worker cache.

№ 08 — EXPORT

One-click PDF.

Send the current document to PDF with all chrome stripped, proper page breaks, and Mermaid intact.

№ 09 — OUTLINE

On-page table of contents.

Automatic outline tracks your scroll position. Toggle it off when you'd rather have the whole room.

№ 10 — RECENTS

Picks up where you left off.

Last folder, last file, last scroll. Resumes between sessions without asking — even when launched via .md double-click.
